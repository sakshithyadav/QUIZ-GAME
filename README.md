# Quiz Game

Python quiz with a console version (`main.py`) and a Flask web app with a 15-minute timer and results pie chart.

## Run locally

```bash
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000

## Deploy live (free cloud — Render)

1. Click this button (sign in with GitHub if asked):

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/sakshithyadav/QUIZ-GAME)

2. On Render, click **Apply** to create the web service from `render.yaml`.
3. Wait a few minutes for the build to finish.
4. Open your live URL (e.g. `https://quiz-game-xxxx.onrender.com`).

Free tier may sleep after ~15 minutes of no traffic; the first visit can take 30–60 seconds to wake up.
